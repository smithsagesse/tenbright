# Put the full source code here

The editable source (src/, build.js, tests, translations, the translation review workbook and the README) is in
**tenbright-mvp.zip**. It is the last file attached in the original chat:
https://claude.ai/chat/1d8f02fd-906c-4fa5-ae9a-a66610593d22

1. Open that chat on your computer and scroll to the very last message, about the superhero Pip, capoeira and the galaxy dive (v22).
2. Download `tenbright-mvp.zip`.
3. Unzip it into this `source/` folder. You should end up with `source/tenbright-mvp/src/app.html`.

If you can't find the file, Claude Code can keep working from the built app in `../app/`. Large changes are
much safer with the source, though.
