  Verdict
  The corrected app is ready for a private family pilot today: it keeps every child record on
  the device, sends nothing to any outside server, and now requires an adult gate and
  parental agreement before a child profile exists. A public launch still needs four things
  only you or a licensed attorney can supply (section 3).

  This is a detailed compliance review against COPPA, the FTC Act, state design codes,
  accessibility and IP. It is not legal advice and does not replace a licensed attorney's sign-
  off, which the plan already budgets.

  What changed in this release: 13 findings, 11 fixed in code and retested, 2 open (contact
  details and the trademark search).

  Verified by automated tests

         The math engine passed 2.1 million checks across all 53 skills.
         A headless-browser walkthrough of every flow passed, including the adult gate, the
         consent bypass, the data view, the privacy notice and phone layout.
         The release build made zero outside network requests, and the build now fails if any
         outside web address appears in the page.

  Checked and found compliant: no ads, analytics, trackers or links out of the child side; no
  streaks, loot boxes, timers on ordinary practice or other manipulative design; Pip says it is
  a computer-made helper; no child free text, chat, camera, microphone or location; no
  efficacy or IQ claims; fonts under the SIL Open Font License, with license files in the
  package; the Vedic history note is accurate; keyboard focus is visible, motion respects
  reduced-motion settings, and the layout works at phone width.


  Blocking items before a public launch
  Four items block a public launch, and none of them is code.

          Operator details (F12): GMIA's legal entity name, mailing address, a monitored
          contact email and a phone number for the privacy notice and terms. Send them and I
          will fill them in.
          Trademark search (F13): USPTO search for "Tenbright" in Class 9 (software) and Class
          41 (education) before public use.
          Attorney sign-off: the licensed privacy attorney reviews the notice, terms, consent
          flow and the accounts plan. This review gives them a head start; it doesn't replace
          them.
          Verifiable parental consent for any server version: the on-device agreement is
          acceptable only because nothing leaves the device. The moment progress syncs to a
          server, the email-plus flow in the accounts plan must replace it.

  The pilot can run before these are done, as long as the families are invited personally and
  know it is a preview.


  How to release
  The app is a single HTML file with no outside dependencies, so it can run from the current
  private link for the pilot and from your own website for the public launch.

  Now: private pilot

     1. Open the Tenbright app page and use its Share menu to share it with pilot families. I
        can't change sharing for you.
     2. Tell families it is a preview and their child's data stays on their device.
     3. Use the Phase 3 test plan for the G3 sessions.

  Later: public launch on your own domain (after section 3)

     1. Upload dist/index.html from the release package to any static host (for example
         Netlify, Cloudflare Pages or GitHub Pages) under your domain.
     2. Serve it over HTTPS only.
     3. Add no analytics or tag scripts; the build check exists to catch exactly that.
     4. Each family's data stays in their own browser, so moving hosts does not move data.
        Families who used the pilot link start fresh on the new address.

  Self-hosting also makes GMIA the operator of record on its own domain, which is cleaner
  for the privacy notice than a shared link on someone else's site.
